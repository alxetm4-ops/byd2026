Conectar BYDMate

En BYDMate: Ajustes → Integraciones → Webhook. Pega esta URL y activa el envío. El carro y este equipo deben estar en la misma red Wi-Fi.

http://…/api/webhook
  1. Abre ADB en el DiLink (lo hace el servicio de localización o el desbloqueo remoto).
  2. Instala BYDMate y concede los permisos del asistente.
  3. Activa el webhook y verifica que el estado cambie a En vivo.
  4. Opcional: activa el envío de coordenadas para ver el carro en el mapa.

Importar viajes y cargas

Lee el backup de BYDMate y llena la pestaña Viajes con tus recorridos y sesiones de carga reales.

  1. En BYDMate: Ajustes → Service & Data → Backup (o “Guardar configuración”), incluyendo las tablas.
  2. Se guarda en Descargas un archivo bydmate_backup_....zip.
  3. Tráelo a este dispositivo y súbelo aquí.
Arrastra el .zip aquí o toca para elegir el archivo

Solo se lee la base de viajes y cargas. Tus preferencias, cuentas y claves no se suben. Si Render se reinicia, vuelve a importar el backup.
